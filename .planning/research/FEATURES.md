# Feature Research — GRACE-GC

来源：论文 §4–§6、§8、§13、附录 F/G；2026-09-15 用户确认范围。

## Table Stakes

| 能力 | 复杂度 | 依赖与验收 |
|---|---|---|
| 研究合同、revision/hash、实验状态 | 中 | 所有真实入口共用校验；缺少必需身份信息不能启动正式实验 |
| 全空间梯度 HT 参考与分配器 | 中 | 有限枚举、p=1 回归、受限概率预算、固定 N |
| tiny LoRA CPU 训练闭环 | 中 | 保留 A/B，token-sum，支持自然 EOS、停止/null、单次更新 |
| 历史基底与预测器 | 高 | 完整梯度 reservoir、Gram 残差、IPW、历史问题隔离、基底刷新 |
| 两阶段 vLLM + verl actor | 高 | 版本锁定、相同快照、RNG、参数布局/分片、全局 N 与校正符号 |
| 核心对照 | 中 | 机制六方法同目标；GRPO/GRPO-short 独立实用轨道 |
| 数学数据、验证器、账本与独立评测 | 高 | split 防泄漏、非重叠 GPU 账本、真实完成的成功统计 |
| 最小证伪与完整 Pilot 配置 | 高 | 学习性 sanity 后审计；留出续写；CI、正交补、成本与失败状态 |

## Research-Specific Differentiators

- 停止样本仍有预测梯度贡献；完成样本包括负预测校正项。
- 直接从同一前缀多次独立续写计算全空间梯度不确定性。
- 在主实验前计算可实现概率下的方差成本比，并允许输出证据不足。
- 计算状态、硬件验证状态、研究证据状态彼此独立。

## Deferred

外部实用方法全复现；A1–A14 完整实验矩阵；代码执行任务与沙箱；多模型规模；多决策点；完整主实验图表与论文写作。不能在 CLI 方法枚举中把尚未实现的基线冒充可运行方法。

## Anti-Features

同批预测器拟合；用投影残差代替全空间；随机幸存数归一化；停止轨迹伪奖励；HT 权重事后裁剪仍宣称无偏；把异种 GPU 时间直接相加成 A100-hours；把合成运行混入真实数据；无 GPU 时用 mock PASS 覆盖硬件测试。
