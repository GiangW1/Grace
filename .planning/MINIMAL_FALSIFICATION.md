# 最小证伪：代码完成后直接用小配置运行

**当前状态：** 训练/评测/审计脚本已在仓库；本机 CPU 可跑；真实 GPU 实验未跑。
**顺序：** 按 README 全流程：单卡 smoke Full-PG → Pilot Full-PG → Pilot GRACE。完整 4 卡尚未接线。

## 简单使用方式

1. 指定模型或 checkpoint、数据路径、方法、seed 和少量规模参数。
2. 用短跑检查数据到更新的完整链路，观察 Full-PG/GRPO 是否学习。
3. 对同一前缀独立续写，计算完整梯度不确定性和答案不确定性；与 GRACE/核心对照比较。
4. 输出真实梯度误差、成功率、运行时间、可省计算及可计算的区间，再决定是否扩大规模。

这些是建议的运行顺序，不是程序必须逐项通过的解锁流程。允许直接审计已有 checkpoint、只跑一个对照、缩小题目数或减少续写数。

## 参数尽量少

现有论文参数作为默认参考：Qwen3-4B-Base、q/v LoRA r=16、训练最长 2048 / 评测 4096 token、训练温度 1、单决策点 512、p_min=0.2、beta=0.5、k=8、`format_warmup` 256 步（smoke 32）。CPU 测试使用 tiny model。

题目数、每题起步数、决策点、独立续写数、快照数和训练步数可以直接调整。首次先用能快速跑完的规模；不固定必须24题、必须两个快照或必须9,216条续写。增加快照和样本有助于判断稳定性，是后续实验选择。

若使用纯 LoRA 初始化快照，报告注明可能存在 A 梯度退化；仍允许用于调试。已有非初始化 checkpoint 可直接用于现象审计，无需先重新训练指定步数。

## 输出什么

- 原始配置、seed、实际可获得的模型/数据/软件版本。
- 前缀/后缀 token、奖励、p/Z、梯度范数与坐标；停止轨迹 reward=null。
- 全空间梯度统计、rho_L/rho_A、学习/答案完成时间以及实际可计算的 LAG、ELF、PLC。
- 预测器残差、正交补诊断；实际 p 下的方差×成本，与完整采样比较。
- 同预算独立解题结果、运行时间、生成/训练/预测器开销，以及真实验证的困难题首次成功。
- 样本量、自然结束/截断/删失和区间；量无法计算时给出空值及原因，继续保存其他结果。

论文中答案未定、非零信号、Wilson 区间等条件属于“如何分析这批数据”。提供全体样本摘要和按这些条件筛选的摘要；筛选为空时正常输出。不能把筛选结果当作是否允许训练、审计或保存结果的判断。

## 不增加实验门槛

- 不要求先填写 claims.yaml/source_registry.json、批准配置、锁齐所有 hash。
- 不要求先满足最低有效样本量、置信区间宽度或盈利预测，才允许运行。
- 不自动执行 Go/No-Go，不因结果弱、负结果或不确定而停止后续用户配置的实验。
- 论文原有数值目标可在报告中比较，作为信息展示；不是试跑准入条件。
- 理论闭式有适用范围时标注，不适用就报告实际 p 的数值方差/成本；无需等待理论全部重推。
- 启动只检查程序实际需要的文件、依赖、设备和参数；错误信息说明怎么修复，不要求额外认证报告。

## 简单复现

每次运行存一份配置、日志与结果。seed 和数据分割保持可复现；当前批不能用未来奖励训练预测器，审计统计的拟合/评估用独立续写。落盘文件清单见 README「看哪些文件」。正式写论文时再根据已积累的真实记录整理预注册、完整比较与附录材料。

本机合成测试与服务器实测分开保存，A100 和5090分别记时。是否继续扩大实验由结果和实际需要决定，不写成一套额外审批系统。
